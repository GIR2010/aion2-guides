# Aion 2 — интерактивный гайд

Фан-сайт с гайдами по Aion 2 на русском и английском: прокачка, классы, навыки, стигмы, экипировка.
План работ — [`docs/plan.md`](docs/plan.md).

## Команды

| Команда | Что делает |
|---|---|
| `pnpm install` | Установить зависимости |
| `pnpm dev` | Локальный сервер на `localhost:4321` |
| `pnpm build` | Собрать сайт в `dist/` (заодно проверяет данные по схемам) |
| `pnpm preview` | Посмотреть собранный сайт |
| `pnpm test` | Тесты правил прокачки |
| `pnpm sync:text` | Сверить названия и особенности умений с текстами клиента (`--write` — записать) |
| `pnpm extract:tables` | Извлечь факты из таблиц клиента: опыт и очки по уровням, требования и стоимость уровней умений (`--write` — записать) |

## Структура

```text
src/
  content.config.ts      схемы всех данных (Zod) — сборка падает, если данные не сходятся
  data/
    sources.json         реестр источников, на которые ссылаются факты
    classes/*.json       классы и их навыки
    milestones.json      что открывается на каких уровнях (общее для всех)
    routes/*.json        маршруты прокачки фракций
    leveling/*.json      пошаговые планы прокачки класса
    game/levels.json     таблица уровней из клиента (генерируется extract:tables)
  content/guides/{ru,en}/*.mdx   тексты гайдов
  components/            таблицы навыков, интерактивный таймлайн уровней (React)
  i18n/ui.ts             строки интерфейса RU/EN
  pages/[lang]/...       страницы: /ru/..., /en/...
raw/screenshots/         скриншоты из игры для проверки данных (не в git)
raw/client/<сборка>/     выгрузка текстов и таблиц клиента (не в git)
scripts/                 инструменты работы с данными
```

## Правила данных

- У каждого факта есть `status` и `sources`:
  `verified` — проверено в игре, `multi-source` — 2+ источника, `single-source` — 1 источник, `unknown` — нет данных.
- Названия — только официальные, из текстов клиента (`pnpm sync:text`). Термины как в игре: «умения», «очки умений», «обломки стигмы», «Даэванион».
- Из выгрузки клиента на сайт попадают только факты (названия, цифры, механики), не сами файлы и не тексты целиком.
- Тексты с чужих сайтов не копируем, факты сверяем.

## Деплой

Push в `main` → GitHub Actions собирает сайт и публикует на GitHub Pages
(`Settings → Pages → Source: GitHub Actions`).
