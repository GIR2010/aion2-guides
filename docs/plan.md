# План работ: интерактивный гайд по Aion 2

Версия 3 от 2026-10-21.

## Цель первой версии

Гайд на русском языке по прокачке персонажа **1→45** (кап первого глобального сезона) для каждого из 8 классов. Состав:

- маршрут прокачки по уровням: зоны, квесты, данжи, самый быстрый путь до 45;
- развитие класса по уровням: какие навыки качать, когда и зачем;
- стигмы: открытие на 22 уровне, слоты на 22/27/32/37 уровнях, приоритет по классам;
- комплекты экипировки по этапам прокачки;
- интерактив: карта, конструктор сборки, выбор и заточка экипировки, оценка урона или лечения персонажа для пати.

Дальше гайд станет игровым **оверлеем** на той же кодовой базе.

## Технический стек

- **Веб:** Astro + TypeScript. Гайды пишутся в MDX и собираются в статику (хорошо для SEO). Интерактивные модули сделаны как React-острова. Поиск по сайту на Pagefind.
- **Данные:** JSON или YAML в `data/` со схемами на Zod. Они проверяются при сборке и в CI.
- **Движок расчётов** (`packages/calc`) — отдельный TypeScript-модуль без зависимостей от UI. Его используют и сайт, и оверлей; формулы покрыты тестами.
- **Карта:** Leaflet с `CRS.Simple`, тайлы нарезаются из скриншотов карты мира.
- **Оверлей (этап 2):** Tauri — прозрачное окно поверх игры с режимом «клики проходят насквозь» и горячими клавишами. Игра должна работать в оконном режиме без рамки. **Оверлей не читает память игры, не перехватывает трафик и не внедряется в процесс.** Он только показывает гайд, карту и калькуляторы, чтобы не попасть под NCGuard.
- **Хостинг:** Cloudflare Pages или GitHub Pages.

## Этапы

### Этап 1. Каркас (1–2 дня)
- git, репозиторий, CI, деплой предпросмотра.
- ✅ Один пакет Astro (монорепозиторий отложен до оверлея): данные в `src/data`, схемы в `src/content.config.ts`, расчёты будут в `src/lib/calc`.
- Навигация: Классы / Прокачка / Стигмы / Экипировка / Карта / Конструктор / Калькулятор.
- Глоссарий RU↔EN. Русские названия берём из официальной локализации и проверяем в игре.

### Этап 2. Модель данных (2–3 дня)
Схемы сущностей:
- `Class` — роль, оружие, сильные стороны;
- `Skill` — уровень открытия, тип (мастерство, стигма или пассивка), эффекты по уровням навыка, специализации;
- `Stigma` — 13 на класс, стоимость в осколках (1/2/4/8 за ступень, 75 осколков до 20 уровня), специализации на 5/10/15/20 уровнях;
- `Item` и `ItemSet` — слот, требуемый уровень, статы, источник получения, бонусы комплекта;
- `Enchant` — таблица заточки: шанс, стоимость, прирост статов по ступеням;
- `Zone`, `MapPoint`, `Quest`, `Dungeon`;
- `LevelMilestone` — что открывается на каждом уровне: доска Daevanion на 12 и 16 уровнях, стигмы на 22 уровне, слоты, полёт и т. п.

### Этап 3. Контент: прокачка 1→45 (около 2 недель, основной объём)
1. **Общий маршрут 1→45.** По диапазонам уровней: зона, сюжетные (жёлтые) квесты, полезные побочные (синие) квесты ради очков Daevanion, запечатанные данжи. Ориентир по времени — 12–15 часов для опытного игрока.
2. **Таймлайн открытий по уровням.** Одна таблица на все системы: что открывается и что сделать сразу.
3. **8 классовых гайдов** по одному шаблону:
   - роль и стиль игры;
   - навыки по уровням: что брать и что качать в первую очередь для соло-прокачки;
   - стигмы на каждый слот (22/27/32/37), порядок прокачки, замены для пати и соло;
   - комплекты экипировки по этапам (ранний, средний, перед 45);
   - приоритет статов, ошибки новичков.
4. **Экипировка и заточка:** система усиления, где брать камни, что точить, а что пропускать до капа.

Порядок классов: сначала самые популярные (по статистике gamewith.ai), за ними остальные.

### Этап 4. Интерактивные модули
| # | Модуль | Суть | Оценка |
|---|---|---|---|
| 1 | Таймлайн уровня | Выбираешь класс и уровень и видишь, что делать сейчас: навыки, стигмы, зону, экипировку | 2–3 дня |
| 2 | Конструктор сборки | Класс → навыки и стигмы → экипировка на 18 слотов. Сборка сохраняется в URL, ею можно поделиться | 1–1,5 нед. |
| 3 | Симулятор заточки | Шансы, ожидаемая стоимость, прирост статов | 3–4 дня |
| 4 | Оценка урона и лечения | Ротация × статы × экипировка → DPS/HPS. Сравнение с типичными значениями «для пати». Импорт персонажа по нику через официальный API | 1,5–2 нед. |
| 5 | Карта | Зоны, телепорты, квесты прокачки, ресурсы, запечатанные данжи | 1–2 нед. (сбор точек) |

**Важно для пункта 4.** Формулы урона официально не опубликованы. Поэтому сначала собираем их опытным путём (тесты на манекенах, сравнение с данными из официального API) и только потом показываем цифры. В интерфейсе это «оценка», а не точное значение.

### Этап 5. Оверлей (после стабильной веб-версии)
- Обёртка на Tauri вокруг веб-приложения с компактным режимом под оверлей.
- Режимы: таймлайн «что делать на моём уровне», мини-карта зоны, чек-лист квестов, сборка.
- Горячие клавиши, прозрачность, режим «клики сквозь окно».
- Перед релизом проверить совместимость с NCGuard.

### Этап 6. Сопровождение
- Скрипт `scripts/patch-diff`: сравнивает манифесты клиента и фиксирует новую сборку.
- Чек-лист обновления по патчноуту. Страницы с отстающим `verified_patch` помечаются как устаревшие.

## Риски
- **Расхождения в фан-источниках.** Названия классов различаются (Spiritmaster/Elementalist), цифры между сайтами тоже. Решение: проверка по двум источникам и в игре.
- **Неточная оценка урона без формул.** Решение: калибровка, явная пометка «оценка».
- **Оверлей и античит.** Решение: только отдельное окно, никакого взаимодействия с процессом игры.
- **Скорость патчей.** Решение: `verified_patch` и сравнение манифестов.
