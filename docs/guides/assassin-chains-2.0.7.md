# Связки Убийцы 1–45: основание рекомендаций

Дата: 2026-10-20. Целевая страница: `src/content/guides/ru/assassin-leveling.mdx`.
Проверка относится к снимку глобального клиента 2.0.7 / Steam 25926599.

## Первичные материалы проекта

- `src/data/classes/assassin.json`: официальные названия, эффекты и уровни открытия.
- `src/data/leveling/assassin-asmodian.json`: выбранный порядок стигм: Клык хищника (22), Иллюзорный двойник (27), Обет ускорения (32), Вероломная атака (37). Все стигмы сами по себе открываются на 22; последующие уровни здесь означают слоты и выбор данного гайда.
- `raw/client/steam-25926599/text/ru-RU/game.json`, ключ `String_UI_SKILL_SETTING_MACRO_DESC_body`: связка работает при удержании, ручной ввод приоритетен, последовательность может не соблюдаться; назначения в Настройки → Клавиши → Общие → Связки навыков; кнопки мыши недоступны для связок в режиме Aion 1.
- `raw/client/steam-25926599/structured/tables/skills/PCContextSkillSlot.json`: строки с ID 25 и 26. Стандартный контекстный слот 7: Вторжение (13360000), Бросок тени (13220000); слот 8: Неистовый шквал (13340000), Удар торнадо (13210000), Пронзание сердца (13350000). Это настройка контекстной панели, а не список автоматически исполняемых шагов. Порядок выбора при одновременных условиях по этой таблице не установлен.
- `raw/client/steam-25926599/structured/tables/skills/SkillCond.json`: условие Убийцы ID 13000001, значок критического попадания, группа состояния 133500081, список вариантов Пронзания сердца. Дополнительно само описание навыка указывает критическое попадание; описание двойника сообщает о снятии перезарядки.

## Авторские решения для прокачки

Базовая связка из Пронзания сердца и Рева зверя — рекомендация, а не подтверждённый оптимальный макрос. Рев выбран завершающим доступным ударом; Быстрый разрез оставлен отдельно для восполнения ОМ. Приоритет между готовыми умениями и поведение конкретной панели требуют проверки в игре, поэтому гайд не обещает строгий порядок макроса.

Взрыв эмблемы вынесен отдельно, чтобы новичок контролировал пять зарядов. Вариант с Взрывом в общей связке указан как упрощение с потерей контроля момента применения. Клык и Взрыв описаны как ручная комбинация с ожиданием попадания, а не атомарный макрос.

Рывки, контекстные реакции, слепота и Снятие шока оставлены под ручным контролем. Бафы тоже отдельные: на коротких перебежках их не стоит автоматически расходовать. Конкретные клавиши — пример, они не выдаются за стандартные назначения клиента.

Исправлена соседняя ротация: двойник не предлагается до его установки в слот на 27 уровне, а Бросок тени не обещан против иммунного босса. Ошеломление для Неистового шквала отделено от оглушения.

Рекомендации не используют особенности уровней 12–16 или эндгейм-снаряжение как обязательное условие. Они ещё не имеют статуса проверенной в игре раскладки.
